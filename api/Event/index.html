Event

A minimal signal, split into its two capabilities so producers and consumers can be handed different halves: 

local onThing, fireThing = Event()
local disconnect = onThing(function(value)
	print("got", value)
end)
fireThing(123)
disconnect()

(Args...) → ()--

Fires the event to every current listener.

Creates an event and returns its connect and fire halves. Listeners run on their own threads via task.spawn, so a yielding or erroring listener never blocks the firer or the other listeners.
