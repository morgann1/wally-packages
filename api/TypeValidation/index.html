TypeValidation

Runtime type validators for common Roblox value types. Each validator returns true when its input matches the expected shape and false otherwise, making it suitable for assertion-style precondition checks.

Exposed validators:

  • validateCFrame
  • validateInstance
  • validateNumber
  • validateSimpleTable
  • validateVector3

Functions​

validateInstance​

</>
TypeValidation.validateInstance(
value: unknown,
expectedClass: string--

Class name to check with IsA.

) → boolean

Validates that the value is a real Instance of the expected class (per IsA, so subclasses pass). Guards against 'imposter' tables sent through remotes with keys mimicking instance properties.

validateVector3​

</>
TypeValidation.validateVector3(value: unknown) → boolean

Validates a Vector3 with no NaN components (a Vector3 compares unequal to itself when any component is NaN).

validateSimpleTable​

</>
TypeValidation.validateSimpleTable(
value: unknown,
keyType: string,--

Required typeof of every key, e.g. "string".

validator: (unknown) → boolean--

Validates each value.

) → boolean

Validates a homogeneous table: every key must have the given typeof and every value must pass the validator. Compose with the other validators, e.g. validateSimpleTable(value, "number", validateVector3).

validateCFrame​

</>
TypeValidation.validateCFrame(value: unknown) → boolean

Validates a CFrame whose position and look vector are both NaN-free.

validateNumber​

</>
TypeValidation.validateNumber(value: unknown) → boolean

Validates a number that is not NaN. Note infinity passes; add a range check at the call site when bounds matter.
