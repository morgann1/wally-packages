IconRamp

Picks the right raster icon for a display size from a "ramp": an array of the same icon exported at multiple sizes, each with per-theme variants.

Types​

IconVariant​

</>
type IconVariant = "light" | "dark" | "mono"

Theme variant an icon asset is drawn for.

Icon​

</>
type Icon = {
size: number,
variants: {[IconVariant]: string}
}

One exported size of an icon; variants maps each theme to its asset id.

IconRamp​

</>
type IconRamp = {Icon}

All exported sizes of one icon.

Properties​

Types​

</>
IconRamp.Types: {
IconVariant: Def,
Icon: Def,
IconRamp: Def
}

ty runtime definitions matching the exported types, for validating ramps loaded from untrusted data. IconRamp drops invalid entries rather than rejecting the whole array.

Functions​

selectNearestSize​

</>
IconRamp.selectNearestSize(
ramp: IconRamp,
targetSize: number--

Size the icon will be displayed at, in pixels.

) → Icon?

Returns the smallest icon in the ramp that is at least targetSize pixels, so icons are only ever downscaled, never blurred upward. Falls back to the largest icon when the ramp has nothing big enough; returns nil only for an empty ramp. ramp itself is left unsorted.
