Leader

Elects a single leader among plugin instances running in the same Studio session, over an Interposer peer network. Used when several copies of a plugin coexist (local dev rig plus installed copy) and exactly one should own a shared resource such as a toolbar.

Election: each peer first asks the others whoIsLeader; a peer that claims itself is believed. If nobody knows, only the peer with the lexicographically lowest id self-elects (ids are GUIDs, so every peer agrees), which avoids the co-arrival race where all peers elect themselves in the same tick. A leader that shuts down hands leadership to another peer on the way out.
