ty

Runtime type definitions that mirror Luau types, built by chaining combinators off base defs: 

local IconVariant = ty.Just("light"):Or(ty.Just("dark")):Or(ty.Just("mono"))
local Icon = ty.Struct({ exhaustive = true }, {
	size = ty.Number,
	variants = IconVariant:MapOf(ty.String),
})
if Icon:Matches(value) then ... end
local icon = Icon:CastOrError(value)

Every def answers Matches (boolean) and Cast (a Maybe carrying the converted value or a nested reason string). Combinators are available both as functions on ty and as methods on any def, where the def becomes the first argument.

) → boolean--

Whether x fits, without converting.

Cast: (
self: Def,
x: unknown
) → Maybe<unknown>--

Converts x, or a None explaining the mismatch.

}

Properties​

Unknown​

</>
ty.Unknown: Def

Matches anything; casts pass values through unchanged. Its opposite is ty.Never, which matches nothing.

Number​

</>
ty.Number: Def

typeof-based defs for the primitive types: ty.Number, ty.Boolean, ty.String, ty.Thread, ty.Table and ty.Function.

True​

</>
ty.True: Def

Literal defs for the three singleton values: ty.True, ty.False and ty.Nil.

Functions​

IntoDefault​

</>
ty.IntoDefault(
innerDef: Def,
defaultValue: any--

Substituted when the input is nil.

) → Def

Casts nil to defaultValue; any other value goes through the inner def. Use for optional fields that should come out filled in.

Tuple​

</>
ty.Tuple(
options: {exhaustive: boolean},
tuple: {Def}--

Def per position.

) → Def

The numeric-keyed counterpart of Struct: each position has its own def. Same missing-field and exhaustive semantics.

Struct​

</>
ty.Struct(
options: {exhaustive: boolean},
object: {[string]: Def}--

Field name to the def its value must satisfy.

) → Def

Matches string-keyed tables field-by-field. Casting rebuilds the table from the declared fields, so a missing field fails unless its def is Optional or IntoDefault. With exhaustive = true, keys outside the declaration reject the cast; otherwise they are silently dropped.

CastOrError​

</>
ty.CastOrError(
def: Def,
x: unknown
) → unknown--

The cast value.

Casts x through the def and returns the converted value directly, erroring with the cast's reason chain instead of returning a Maybe. The assertion-style entry point at trust boundaries.

Errors

TypeDescription
Could not castWhen `x` does not fit the def.

IntoTagged​

</>
ty.IntoTagged(
innerDef: Def,
tag: unknown--

Discriminant stored under __tag.

) → Def

Casts through the inner def, then stamps the result with a __tag field for discriminated unions. Table results are cloned before tagging; other values are wrapped as { value = result, __tag = tag }.

Just​

</>
ty.Just(
literal: unknown,--

The only accepted value.

type: string?--

Display name; defaults to tostring(literal).

) → Def

Matches exactly one value, compared with rawequal. Chain with Or for string-literal unions: ty.Just("light"):Or(ty.Just("dark")).

MapOf​

</>
ty.MapOf(
keys: Def,
values: Def
) → Def

Matches dictionaries where every key fits keys and every value fits values. Casting rebuilds the table with both keys and values cast. As a method, the def becomes the key type: IconVariant:MapOf(ty.String).

Predicate​

</>
ty.Predicate(predicate: (unknown) → boolean) → Def

Builds a def from a boolean function; casting passes matching values through unchanged. The escape hatch for checks the other combinators can't express.

Optional​

</>
ty.Optional(innerDef: Def) → Def

Also accepts nil, which matches and casts to nil. The runtime equivalent of Luau's T?.

Typeof​

</>
ty.Typeof(typeString: string) → Def

Matches values whose typeof() equals the given string. Works for Roblox datatypes too: ty.Typeof("Vector2"), ty.Typeof("Instance").

IgnoreInvalid​

</>
ty.IgnoreInvalid(innerDef: Def) → Def

Makes a def infallible: values that fit the inner def cast normally, anything else casts to nil instead of failing. Inside Array, this drops invalid elements from the result.

Or​

</>
ty.Or(
first: Def,
last: Def
) → Def

Union: matches values fitting either def. Casting tries first and falls back to last, so put the more specific (or more converting) def first.

IntoNumber​

</>
ty.IntoNumber(
innerDef: Def,
base: number?--

Numeric base for the conversion, as in tonumber.

) → Def--

Casts to a number.

Casts through the inner def, then converts the result with tonumber. Fails when the conversion returns nil.

Array​

</>
ty.Array(
values: Def--

Def each element must satisfy.

) → Def

Matches contiguous numeric arrays whose every element fits values. Casting rebuilds the array with each element cast; wrap the element def in IgnoreInvalid to drop failing elements instead of rejecting the whole array.

Retype​

</>
ty.Retype(def: Def) → Def

Returns the def unchanged; exists purely so call sites can reassert the def's static Luau type. No runtime effect, like Untyped.

Untyped​

</>
ty.Untyped(def: Def) → Def

Returns the def unchanged; exists purely to erase the def's static Luau type at call sites. No runtime effect, like Retype.

IntoString​

</>
ty.IntoString(innerDef: Def) → Def--

Casts to a string.

Casts through the inner def, then converts the result with tostring.

And​

</>
ty.And(
first: Def,
last: Def
) → Def

Intersection: matches values that satisfy both defs. Casting pipes the first def's output into the last, so converting defs compose.

Nicknamed​

</>
ty.Nicknamed(
innerDef: Def,
newName: string
) → Def

Renames a def's ExpectsType so error messages read as your domain name instead of the expanded structural type.
